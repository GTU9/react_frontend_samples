# 이미지 출처 보충

샘플별 전체 자산 경로와 참고 자료는 각 분야별 문서를 참조한다. 상품 이미지 일부는 생성 이미지이며 실제 판매 상품이 아니다. 사진은 가상 기사, 작품, 프로젝트의 분위기를 설명하는 용도로 사용한다.
